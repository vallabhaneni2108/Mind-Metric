ABOUT THE PROJECT

Data meets
student wellbeing.

MindMetric is a student-focused machine learning project exploring the relationship between digital habits, lifestyle patterns and mental health scores.

The application collects assessment inputs, sends them to a FastAPI prediction API and displays the model's output in an interactive dashboard.
